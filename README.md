# Help Find MARS — GitHub Pages

A free static webpage to help locate **MARS**, a missing mixed-breed dog with a white, tan, and black coat.

- **Last seen:** Archer St. Bridge, October 9, 2026
- **Report sightings:** Call or text Brian at **918-896-5590**
- **Photo:** Placeholder is displayed automatically until a picture is uploaded.

## Add MARS’s photo

Upload a clear photo to the repository root and name it **`dog-photo.jpg`** (exactly). The page already points to that filename and switches from the placeholder automatically. If your photo is a PNG or HEIC, convert it to JPG first, or change the filename referenced in `index.html`.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, such as `find-mars`.
2. Upload the files **inside this folder** (`index.html`, `placeholder.svg`, and optionally `README.md`) to the **repository root**, not to a nested folder. You do not need a photo to publish initially.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`; click **Save**.
4. After deployment, your link will look like `https://YOUR-USERNAME.github.io/find-mars/`.
5. Share the page with neighbors, shelters, vets, rescue groups, and local social media groups.

## Update information

Edit the `const dog = { ... }` section near the bottom of `index.html`. The public contact phone is in the webpage; avoid adding personal home addresses. Do not pay supposed finders or share verification codes.
